# Runtime Conditions Guide Site

Runtime Conditions is currently seeking adoption by an established parent
project. The repositories in this organization are split for hands-on usability,
review, demos, and implementation feedback. They are not intended to present
Runtime Conditions as a standalone foundation or competing project.

Start here: https://runtimeconditions.github.io/

## Purpose

This repository contains the static public guide for Runtime Conditions. It is
intended to publish at the organization GitHub Pages root:

```text
https://runtimeconditions.github.io/
```

GitHub Pages serves an organization site from a repository named
`runtimeconditions.github.io`. The current site is plain HTML, CSS, and
JavaScript copied from the original monorepo `site/` directory.

## Local Preview

Open `index.html` directly in a browser, or serve this directory with any static
file server.

## Related Repositories

- `runtimeconditions/spec` - specification drafts, whitepaper, and guides.
- `runtimeconditions/extensions` - first-party extension definitions.
- `runtimeconditions/rc-demos` - runnable end-to-end demos.
